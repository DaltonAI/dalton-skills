# Dalton plugin

Agent skills from [Dalton](https://getdalton.com), in two groups:

| Group | What it covers | Needs a Dalton account |
| --- | --- | --- |
| [`skills/dalton/`](skills/dalton/) | Using Dalton: set it up, build and fix A/B tests, read results. | Yes, with the [Dalton MCP server](https://docs.getdalton.com/advanced/mcp-server) connected |
| [`skills/cro/`](skills/cro/) | General CRO: research and learn about a brand, audit pages, plan tests. | No |

The Dalton MCP server is not part of this plugin. Connect it separately with
your Dalton login: see the [MCP server docs](https://docs.getdalton.com/advanced/mcp-server).

## Install

```text
/plugin install dalton --marketplace DaltonAI/dalton-skills
```
